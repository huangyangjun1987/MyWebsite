# Learning Calendar

## Purpose

学习日历热力图组件 — 以 GitHub 贡献图风格展示每日学习活动密度。

## Requirements

### Requirement: 学习日历热力图

系统 SHALL 在 Dashboard 学习数据页展示学习日历热力图，以类似 GitHub 贡献图的网格形式呈现用户每日学习活动密度。

#### Scenario: 正常渲染日历

- **GIVEN** 用户已登录，API `/api/analytics/calendar` 返回有效月度数据
- **WHEN** 页面加载学习日历组件
- **THEN** 渲染当月日历网格（7 行 = 周一至周日 × N 列 = 当月天数），每格颜色深度映射当日学习时长（0 分钟=空白/浅灰，>0 浅色，>30min 中色，>120min 深色），右侧显示色阶图例

#### Scenario: 切换月份

- **GIVEN** 日历显示当前月份（如 6 月）
- **WHEN** 用户点击向左箭头切换至上月或向右箭头切换至下月
- **THEN** 日历网格更新为对应月份数据，月份标题同步更新（如「2026 年 5 月」），若该月无任何数据则所有格子为空白

#### Scenario: 暗色模式适配

- **GIVEN** 当前为亮色模式
- **WHEN** 用户切换至暗色模式
- **THEN** 空白格子色变为 `gray-800`，浅色至深色梯度在暗色主题下保持可辨识对比度

#### Scenario: 空数据月份

- **GIVEN** 用户在某月无任何学习活动记录
- **WHEN** API 返回空数组 `[]`
- **THEN** 日历仍正常渲染当月网格，所有格子为空白/无颜色，不显示错误提示

#### Scenario: 错误：API 请求失败

- **GIVEN** API `/api/analytics/calendar` 返回 500 或网络异常
- **WHEN** 组件尝试获取数据
- **THEN** 日历区域显示错误提示「数据加载失败」，提供重试按钮
